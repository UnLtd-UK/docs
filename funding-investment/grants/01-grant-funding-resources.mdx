## Overview

This page brings together three spreadsheet-based resources to help you find grant funding, track your applications, and study real-world award data. Whether you are a charity, community interest company (CIC), or social enterprise, these tools support you through the full grant funding cycle -- from identifying funders to managing a pipeline of live applications.

## BLF Responsive Funding Summary

The Big Lottery Fund (BLF) responsive funding summary catalogues over 2,200 grants awarded to community organisations across England. Use it as a reference dataset to understand BLF funding patterns, regional distribution, and the types of projects that have received support.

### What the Spreadsheet Contains

The workbook has a single sheet covering nationally funded projects:

| Column | Description |
|---|---|
| **Organisation** | Name of the funded organisation (e.g. charities, CICs, community groups) |
| **Project Title** | Name of the funded project |
| **Press Summary** | Brief description of the project activities and aims |
| **Local Authority** | The local authority area where the project operates |
| **Constituency** | Parliamentary constituency for the project |
| **Region** | Broader geographic region (e.g. Cumbria, London) |
| **Amount Awarded** | Grant amount in GBP |

The dataset spans health and wellbeing, youth leadership, community engagement, and other social-impact areas. Award amounts typically range from tens of thousands to over a hundred thousand pounds.

## UK Grant Funders List with Sales and Grants Tracker

This is the most comprehensive workbook in the collection. It combines a curated directory of UK grant funders and community foundations with practical tracking templates for grant applications, prospect management, and sales pipelines. It supports you through the full cycle of identifying funding opportunities, applying for grants, and managing commercial relationships.

### Workbook Contents (9 Sheets)

#### How to Create Funder Lists

A guidance sheet with instructions on building targeted funder shortlists. Start here if you are new to grant funding research.

#### Databases and Aggregators

| Column | Description |
|---|---|
| **Name** | Name and brief description of the grant database or aggregator |
| **Link** | URL to the resource |
| **Notes** | Additional details (e.g. number of entries) |

Lists free and paid databases such as Grants Online, Get Grants Funding Finder, and the Jon Matthews Table for discovering grant opportunities.

#### UK Funders

| Column | Description |
|---|---|
| **Funder Name** | Name of the grant-making body |
| **Fund Purpose** | What the fund supports |
| **Fund Suitability** | Types of eligible organisations |
| **Sector** | Thematic sector (e.g. arts, heritage, community) |
| **Funding Amount** | Typical grant range |
| **Other Support** | Non-financial support offered |
| **Application Dates** | Deadline or rolling status |
| **Geography** | Geographic eligibility |
| **Website** | Funder URL |

Contains over 80 UK grant funders with details on eligibility, funding amounts, and application windows. Sectors covered range from arts and heritage to social justice and community resilience, with funding amounts from under 1,000 GBP to over 100,000 GBP.

#### Community Foundations

| Column | Description |
|---|---|
| **Foundation Name** | Name of the community foundation |
| **Geography** | Area covered |
| **Website** | Foundation URL |

Lists over 55 UK community foundations by region, useful for locally targeted funding searches.

#### Grants Tracker

| Column | Description |
|---|---|
| **Funder** | Name of the grant funder |
| **Website** | Funder URL |
| **Contact / Email** | Key contact details |
| **Programme / Award Name** | Specific fund or programme applied to |
| **Application Deadline** | Submission deadline |
| **Amount** | Amount applied for |
| **Status** | Current application status |
| **Likelihood (RAG rating)** | Red/Amber/Green confidence rating |
| **Notes** | Additional context and next steps |

Use this template to track your grant applications through the full lifecycle, from initial enquiry to outcome. It includes a running total of amounts applied for.

#### Prospects List

| Column | Description |
|---|---|
| **Name** | Contact name |
| **Organisation** | Organisation name |
| **Contact Details** | Email, phone, or LinkedIn |
| **Customer Type** | Relationship category (e.g. consultancy, partnership) |
| **Approach Regarding** | Reason for outreach |
| **Contact (Y/N)** | Whether contact has been made |
| **Last Contact** | Date of most recent interaction |
| **Next Steps** | Planned follow-up actions |

Use this template to manage your pipeline of prospective contacts and partnerships.

#### Sales Tracker

| Column | Description |
|---|---|
| **Contact Name** | Lead contact |
| **Organisation** | Organisation name |
| **Sector** | Industry sector |
| **Contact Email / Number** | Contact details |
| **Suitability** | Fit assessment |
| **Status** | Pipeline stage (cold, interested, signing up, etc.) |
| **Interested In** | Product or service of interest |
| **Potential Budget / Deal Size** | Estimated value |
| **Last Contact / Next Contact** | Interaction dates |
| **Owner** | Internal owner of the relationship |

A CRM-style sales pipeline tracker with BANT qualification columns (Budget, Authority, Need, Timing).

#### Guide and Lists

Supporting sheets with dropdown values for suitability ratings, sales process stages, and grant application statuses.

## UK Grant Funders List (Standalone)

If you only need the funders directory and tracking templates without the sales pipeline sheets, this lighter workbook covers the same core content in 8 sheets. It includes the Databases and Aggregators list, the full UK Funders directory (80+ funders), Community Foundations (55+ foundations), the Grants Tracker, Prospects List, Sales Tracker, and Guide and Lists sheets. The column structures match those described above.

This version omits the "How to Create Funder Lists" guidance sheet found in the combined workbook. If you are new to funder research, consider downloading the combined version above instead.

## Choosing the Right Resource

| Resource | Best for | Key contents |
|---|---|---|
| **BLF Responsive Funding Summary** | Researching past BLF awards and regional funding patterns | 2,200+ funded project records with amounts, regions, and descriptions |
| **UK Grant Funders List + Sales and Grants Tracker** | Full-cycle grant and sales pipeline management | 80+ funders directory, community foundations, grant tracker, sales CRM, and guidance on building funder lists |
| **UK Grant Funders List (Standalone)** | Quick access to the funders directory and basic tracking | Same funder data and trackers without the introductory guidance sheet |
